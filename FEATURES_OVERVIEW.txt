⚡ HOW THE SYSTEM WORKS (Agent Flow)
═════════════════════════════════════════════════════════════════════════════

STEP 1: USER INPUT
  User enters: Origin, Destination, Product Type, Type
  System: Routes input to Coordinator Agent

STEP 2: PARALLEL DATA COLLECTION (All at once)
  ├─→ News Agent: Fetches recent disruption headlines
  ├─→ Weather Agent: Queries port weather alerts
  └─→ Port Agent: Checks congestion & pricing
  ⏱️  Time: ~1-2 seconds total

STEP 3: RISK INTEGRATION
  All data combined into single JSON structure
  Risk Assessment Agent processes all signals
  Calculates weighted risk score (0-100%)
  Estimates cost implications
  ⏱️  Time: ~0.5 seconds

STEP 4: ROUTE OPTIMIZATION
  Route Optimizer creates 3 route options
  Calculates distance, time, cost per route
  Assigns efficiency scores
  Compares with current risk level
  ⏱️  Time: ~0.5 seconds

STEP 5: REPORT GENERATION
  Reporting Agent creates comprehensive report
  Formats results for display
  Prepares recommendations
  Structures data for frontend
  ⏱️  Time: ~0.5 seconds

STEP 6: MAP & UI RENDERING
  Results sent to frontend
  Interactive map drawn
  Dashboard populated
  All tabs become clickable
  ⏱️  Time: ~1 second

TOTAL ANALYSIS TIME: 3-5 seconds ⚡

🎯 RISK LEVELS EXPLAINED
═════════════════════════════════════════════════════════════════════════════

🟢 LOW RISK (0-35%)
   Color: Green
   Signal: "System Go"
   What it means: Route is safe, minimal issues
   Action: Proceed with normal procedures
   Insurance: Standard coverage sufficient
   Contingency: Basic planning only
   Examples:
     • Good weather forecast
     • Port operating normally
     • No disruptions reported
     • Clear geopolitical conditions

🟡 MEDIUM RISK (35-65%)
   Color: Yellow
   Signal: "Caution"
   What it means: Some risks present, manageable
   Action: Monitor conditions closely
   Insurance: Enhanced coverage recommended
   Contingency: Prepare backup plans
   Examples:
     • Seasonal storm season
     • Port with moderate congestion
     • Minor disruptions in region
     • Political tension in area

🔴 HIGH RISK (65-100%)
   Color: Red
   Signal: "Warning"
   What it means: Significant risks, action needed
   Action: Consider alternative routes
   Insurance: Maximum coverage essential
   Contingency: Activate backup procedures
   Examples:
     • Active typhoon/hurricane
     • Port closure or major strike
     • War/conflict in region
     • Multiple disruption signals
