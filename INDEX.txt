📊 WHAT THE SYSTEM ANALYZES
════════════════════════════════════════════════════════════════════════════════

6 INTELLIGENT AGENTS:

1. 📰 NEWS AGENT
   Analyzes disruptive headlines & market news
   Outputs: Articles, risk factors, disruption keywords

2. ⛅ WEATHER AGENT
   Monitors port weather & storm alerts
   Outputs: Alerts, severity, forecast

3. ⚓ PORT AGENT
   Checks congestion, wait times, pricing
   Outputs: Congestion level, port charges, customs info

4. 🔍 RISK ASSESSMENT AGENT
   Aggregates all data into risk score
   Outputs: Overall risk (0-100%), confidence level

5. 🗺️ ROUTE OPTIMIZER AGENT
   Generates 3 alternative routes
   Outputs: Routes with distance, time, cost, risk

6. 📄 REPORTING AGENT
   Creates comprehensive analytical report
   Outputs: Executive summary with recommendations

🔧 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Problem: npm install fails
  Solution: 1) Ensure Node.js is installed
            2) Run from d:\Hackathon folder
            3) Check internet connection

Problem: Port 5000 already in use
  Solution: Change PORT in .env file
            OR: Kill process using port 5000

Problem: Frontend not connecting to backend
  Solution: Ensure backend server is running
            Check if backend shows "Server running..."
            Check F12 console for errors

Problem: Map not loading
  Solution: Check internet (uses CDN)
            Clear browser cache
            Try different browser

Problem: Analysis not working
  Solution: Check backend terminal for errors
            Verify origin/destination are valid ports
            Try different port combination
